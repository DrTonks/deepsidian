## 修复内容

- 自动发现支持 Apple Silicon `/opt/homebrew`、Intel `/usr/local`、PATH 中的 nvm 安装和自定义 npm prefix；保留 Windows roaming npm 路径。显式路径优先，不启动 shell，也不把 Electron 当作 Node。
- 取消超时显式使用 `node:timers`，避免 renderer 的 DOM timer 没有 `.unref()`。
- 用量独立保存在轨迹结构中，避免长回复的展示快照截断影响统计；兼容旧版有效 JSON。已经截断且未保存结构化用量的旧记录无法据此恢复。
- 侧栏注册 Obsidian `Scope`，避免宿主抢先处理 macOS Cmd+Enter。仅学习问题输入框触发发送，输入法组合期间不发送。
- CI 的基础检查和手动集成测试均配置 Windows、macOS、Linux 矩阵。

## 整合复审与修复（2026-09-14）

三个子 agent 分别复审运行时、会话与指令、记忆存储。除了保留初次四项 macOS/轨迹修复，本次还修复：

- 会话准备期取消没有生效：立即确认取消，阻止取消请求提交模型，并允许立即重试。确定性测试覆盖模型查询、图片保存、stat、新建、恢复与已有会话等 8 个场景。
- 长问题在 12000 字符处被静默截断：保留完整问题，由整体 40000 字符预算拒绝超限输入。
- 主进程先校验旧上下文、后发送新上下文：先捕获，再校验并复用同一份冻结提示词。
- `/goal` 保存失败仍使用新目标：失败恢复原目标。
- `/new` 未等待持久化且无法反馈失败：新建时阻止并发修改，等待保存，失败恢复原会话；所有入口处理异步结果。
- 记忆管理保存一项或切换标签会丢失其他草稿：保留每项未提交编辑，仅清除已成功提交的内容。

历史搜索真实浏览器组件的 9 项检查通过，覆盖标题/正文匹配、键盘与焦点、busy 状态、异步选择和 dispose。
