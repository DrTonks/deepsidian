## macOS 原生升级与分支

在 Obsidian 1.13.7 的独立演示库中，将 0.7.1 的三个发行文件替换为 0.7.2，保留设置、聊天和运行时，然后通过命令面板重载。

1. 在同一父会话的第一条完整回答处，分别创建两个分支，标题为 `原标题（1）` 和 `原标题（2）`。
2. 从分支（2）继续分支，标题为 `原标题（3）`，来源指向分支（2）。
3. 重载 Obsidian 后，分支（3）的标题、继承消息及来源保持正确。
4. 再次分支生成 `原标题（4）`，没有重复编号或叠加后缀。
5. 检查持久化数据：新建四个分支各继承两条消息；原有六个会话的标题与消息均未改变，测试库四篇 Markdown 笔记的 SHA-256 均保持不变。

这次升级验收未修改用户博客库。三文件全新启动另由本轮集成测试覆盖；上次原生全新安装记录见 [0.7.1 验收](VALIDATION-0.7.1.md)。
