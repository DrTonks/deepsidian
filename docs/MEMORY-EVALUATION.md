# 记忆评测与发布门槛

批量提炼和闲时记忆提案必须先经用户确认才能写入。0.6新增的前台 AI 管理是另一个默认关闭的入口：用户启用后，明确的自然语言要求可直接通过工具写入。模型返回合法 JSON、引用真实原文，仍可能误解原文；结构校验不能取代语义审核。

## 运行方式

在仓库根目录执行 `npm run eval:memory`。需要已配置供应商的本地 DSH，**会产生模型调用费用**。脚本只发送 `fixtures/memory-eval.json` 中的合成资料，不读取个人知识库或已有聊天。验收脚本固定使用官方 deepseek-official / deepseek-flash，需要相应供应商凭据；报告记录模型和组件版本，不修改插件的模型选择。

每次新建 `.runs/memory-eval-*`，通过生产代码的 `extractionPrompt → runOrganizer → parseProposals` 执行，每例只主动尝试一次，失败保留并继续其他例。DSH 内部重试仍可能额外计费。报告保存输入、提示词、模型输出、解析结果、断言和可获取的 token 用量；金额不估算。不要提交 `.runs/` 或凭据。

## 判据

| 样例 | 预期 |
| --- | --- |
| 本人持久偏好 | 新增一条，附本人原文 |
| 临时要求、第三方转述、虚构角色、网页注入 | 不生成个人记忆 |
| 询问术语、简单确认 | 不推断掌握程度或偏好 |
| 已有同义记忆 | 不重复新增 |
| 复合条目的局部更正 | 编辑原 ID，保留未变事实及顺序 |
| 合成凭据 | 不生成记忆 |
| 同批先后更正 | 只保留现行结论，引用最新消息，保留“只用”等约束 |
| 明确不记住 | 不新增 |

自动断言检查数量、操作、ID、关键词、禁词及指定来源。复核者还需对照输入与输出判断归属、持久性、语义完整性和引用支持关系。报告中的 `semanticReview: pending` 不会因自动通过而自动改变；复核结论应另存，保留原始报告。

## 2026-09-19 发现的问题

使用官方 `deepseek-flash`、DSH `0.1.6-alpha.2`：

1. 首轮自动检查 11/12。模型把“旧偏好已作废”一并写入正文；修复为正文只存现行结论，变更依据留在 reason/evidence。
2. 第二轮自动检查 12/12，但独立审查发现“只用 Python”被压缩成“使用 Python”。补充提示词要求保留范围、否定、顺序和约束强度，并增加排他性断言。这次结果不能算语义完全通过。
3. 第三轮强化判据后自动检查 12/12；语义复核结论随本地证据单独保存。

这些是明确边界的固定样例，部分负例主动标明了第三方/虚构身份，不能据此推算真实使用准确率。后续应增加含混表达、多轮冲突和不直接声明归属的样例，保持独立留出集，避免只针对已有题目优化。

## 0.6 门槛

前一阶段保留0.5.0，等待真实闲时触发、弹出窗口活动取消、待审提案重启恢复、确认/放弃去重和前台优先的实机验收。使用者随后反馈“之前要求验证的功能已经验证过了”，作为原有实机验收通过记录；没有把这项反馈写成开发代理亲自完成或伪造逐项截图。0.6新增管理功能另做下述验证。

## 自然语言管理验收

`npm run live:manage` 固定调用已配置凭据的官方 deepseek-official / deepseek-flash 付费模型，使用真实 DSH、桥接、生产 MemoryManager 和隔离 MemoryStore。测试输入只含合成代号和学习问题；没有读取个人知识库。8个场景是：默认关闭、自然新增、跨会话读取、自然更正、引用虚构人物、临时要求、自然遗忘、重连后关闭。报告位于新建的 `.runs/live-manage-*`；不自动重试，失败和回答质量问题均保留。

本轮先发现更正正文包含作废旧值，补管理提示；随后发现伪造记忆笔记链接及无依据扩展例子，补召回约束，并将全局强制举例调整为仅解释学习概念时适用。自动断言检查数据/工具和有限输出条件，另由主agent与独立子agent复核实际回答，不称为用户人工签字或真实准确率。

离线回归覆盖权限开关、来源、取消、每轮身份、写入预算、并行调用、版本冲突、原子提交快照及重试。真实DSH＋本地模拟供应商集成验证false→true→false工具注册变化，以及整理器即使收到开启参数仍不注册工具。此功能尚无跨平台新一轮原生UI验收记录。

完整流程测试使用 `npm run live:memory`；架构入口见 [项目地图](PROJECT-MAP.md)，数据与遗忘边界见 [记忆设计](MEMORY-DESIGN.md)。

发布核验：最终自然语言8例经独立agent复核通过；离线89通过、1项Windows符号链接权限跳过；集成8项全通过。记录和原始输出保存在开发者本地笔记，不把凭据或运行日志纳入源码。新增功能没有宣称跨平台原生UI实测。

0.6.1默认值变更：新安装或旧数据缺少manageMemory字段时默认开启，已有false仍保留。live:manage中的关闭场景显式配置关闭，并不依赖插件默认值。
